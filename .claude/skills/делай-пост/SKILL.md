# /делай-пост — пост в качестве агентства, а не «голого Клода»

**Зачем скилл существует.** Знания агентства (как мы пишем крючки, какие
композиции/типографику/палитры используем, reverse-prompt для fal.ai) лежат в
git, но в контекст сами не подгружаются. Если делать пост «на лету» — выходит
самая базовая версия: скучный текст, случайные шрифты, пустые фоны. Этот скилл
**принудительно** заливает накопленный опыт в контекст до первой строки текста
или HTML.

## Железное правило

**Не пишешь ни текста поста, ни HTML, ни промпта для картинки, пока не прочитал
все файлы из обязательного списка ниже.** Прочитал — только потом работаешь.

«Я и так знаю как писать посты» / «это простой пост» / «файл большой, прочитаю
по диагонали» — это и есть путь к базовому качеству. Читай полностью.

## Обязательно прочитать ПЕРЕД работой (в этом порядке)

Знания агентства (общие, не зависят от клиента):

1. `global/standards.md` — чек-лист качества поста
2. `global/brand/design-system.md` — дизайн-система bit&pix
3. `agents/designer/knowledge/references.md` — **главный файл**: накопленные
   визуальные паттерны и разборы (Нежность / Технологичность / Роскошь /
   Энергия). 60 КБ — читать целиком, это антидот к «скучно».
4. `agents/designer/knowledge/compositions.md` — рабочие композиции карточек
5. `agents/designer/knowledge/feedback_log.md` — на каких правках уже обжигались
6. `agents/copywriter/knowledge/patterns.md`, `hooks.md`, `feedback_log.md` —
   приёмы копирайтинга (часть пока пустая — это нормально, наполняется со
   временем; прочитать всё равно)
7. `.claude/skills/fal-ai/references/prompt-engineering.md` — reverse-prompt
   методология для генерации картинок

Знания о конкретном клиенте:

8. `projects/{ProjectID}/voice.md` — голос бренда (приоритет, перекрывает всё)
9. `projects/{ProjectID}/context.md` — бриф, табу, ЦА
10. `projects/{ProjectID}/strategy.md` — рубрикатор, форматы, KPI
11. `projects/{ProjectID}/overrides.md` — личные «запомни / не делай» клиента

Если какого-то файла клиента нет — отметь это оператору, не выдумывай.

## После загрузки — рабочий процесс

1. **Текст** — по `.claude/agents/copywriter.md` (структура поста, крючок, CTA,
   правила). Можешь звать сабагента `copywriter` через Agent tool, можешь писать
   сам — но строго по тем же правилам и знаниям.
2. **Визуал** — по `.claude/agents/designer.md`: визуальный план →
   fal.ai-промпты (только `nano-banana-2` / `gpt-image-2`, методология из
   prompt-engineering.md) → HTML по таблице форматов → рендер → S3. Аналогично:
   можно звать сабагента `designer`.
3. **Качество** — перед выдачей оператору сверься с `global/standards.md`:
   жирная читаемая типографика, осмысленный подбор шрифтов (не дефолт),
   fal.ai-фон/текстура (не пустой фон), контраст, формат под платформу.

## Красные флаги — СТОП, ты скатываешься в базовое качество

- Пишешь текст/HTML, не прочитав `references.md` и `prompt-engineering.md`
- Шрифт выбран «наугад», без опоры на design-system.md / references.md
- Текст мелкий/тонкий, пустой фон без fal.ai-ассета
- «Прочитаю knowledge если понадобится» — нет, читаешь ДО работы
- Пост звучит как «Сегодня мы расскажем…» — крючка нет

**Любой из них = вернись к обязательному списку и прочитай то, что пропустил.**
