## Lessons / разбор ошибок и инцидентов

### 1. Жирный в заголовках пунктов — неправильно

Написал «1️⃣ **Нет ответа на вопрос «кому это нужно»**» — оператор поправил на «1️⃣ Нет ответа на вопрос «кому это нужно»» без форматирования.

**Почему:** в Telegram жирный в заголовках пунктов создаёт ощущение корпоративного шаблона. Голос Sparta — живой и прямой, без лишнего форматирования.

**Как не повторить:** заголовки нумерованных пунктов — обычный текст без bold. Правило в памяти.

### 2. Лишние отступы внутри блока пунктов

Ставил пустую строку между пунктом и следующим заголовком пункта. Оператор убрал.

**Как не повторить:** внутри блока 1️⃣/2️⃣/3️⃣ — всё плотно, без пустых строк. Пустые строки только между логическими блоками (введение / нумерованный блок / заключение).
