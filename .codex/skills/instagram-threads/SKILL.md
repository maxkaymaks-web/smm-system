# Instagram + Threads: шаблоны и правила

## Instagram — карусель (основной формат)

### Структура карусели (5–8 слайдов)

| Слайд | Назначение | Что писать |
|-------|-----------|------------|
| 1 — Обложка | Хук + стоп-скролл | Главный тезис / боль / цифра. Максимум 7 слов. |
| 2 | Раскрытие проблемы | Почему это важно. 2–3 строки. |
| 3–6 | Тело | Один тезис = один слайд. Цифры, факты, шаги. |
| Предпоследний | Итог / вывод | Чёткий takeaway. |
| Последний | CTA | Одно конкретное действие. |

### Хуки для обложки карусели

**Цифровые:**
- «[N] причин, почему…»
- «[N]% бизнесов делают это неправильно»
- «За [время] мы сделали [результат]»

**Проблемные:**
- «Вы теряете деньги на [X]»
- «Почему [X] не работает»
- «Ошибка, которая стоила нам [X]»

**Любопытство:**
- «Мы раскрываем [секрет/процесс/кейс]»
- «То, о чём не говорят в [нише]»
- «Как [неожиданный результат] за [срок]»

### Подпись к карусели

```
[Хук первой строки — дублирует обложку или усиливает]

[2–3 строки контекста]

[Пункты или абзацы основного смысла]

[CTA]
```

Длина: 150–300 слов оптимум. Первые 2 строки — самые важные (до «ещё»).

### CTA для Instagram

- «Сохрани, чтобы не потерять»
- «Напишите в Direct — расскажем подробнее»
- «Запишитесь на демо [ссылка в шапке профиля]»
- «Поделитесь с тем, кому актуально»
- «Что думаете? Напишите в комментариях»

## Instagram — требования к посту

- **Холст:** 1080 × 1350 px (вертикаль) — приоритет
- **Альтернатива:** 1080 × 1080 px (квадрат) для отдельных кейсов
- **Слайдов в карусели:** 5–10 (оптимум 6–8)
- **Текст на слайде:** не более 40 слов, крупный, читаемый с телефона
- **Хэштеги:** по договорённости с проектом (по умолчанию — без хэштегов)

## Threads — форматы

Threads = текстовая соцсеть. Главное — первый пост треда или одиночная мысль.

### Одиночный пост (короткий)

```
[Сильное утверждение / факт / вопрос]

[1–3 строки раскрытия]

[Опционально: CTA или реакция]
```

Длина: до 500 символов. Оптимум — 100–250 символов.

### Тред (длинный)

```
Пост 1: [Хук — главный тезис, без раскрытия]

Пост 2: [Контекст / проблема]

Пост 3–N: [Пункты, шаги, аргументы — по одному на пост]

Последний пост: [Вывод + CTA]
```

Оптимум: 4–7 постов в треде. Каждый пост — отдельная законченная мысль.

### Хуки для Threads

- Утверждение против мнения большинства
- Неожиданный факт из практики
- Вопрос, на который есть неочевидный ответ
- «Я сделал X. Вот что получилось»

### Форматы для Threads

| Формат | Длина | Пример использования |
|--------|-------|---------------------|
| Горячий тейк | 1 пост, до 150 симв. | Мнение по тренду, провокация |
| Мини-кейс | 1 пост, 250–400 симв. | Результат + что сделали |
| Тред-инструкция | 5–7 постов | Как сделать X шаг за шагом |
| Тред-разбор | 4–6 постов | Разбор ошибки / кейса |
| Вопрос-вовлечение | 1 пост | Запуск обсуждения |

### CTA для Threads

- «Что думаете?»
- «Сталкивались с этим?»
- «Ещё больше — в Instagram (ссылка в профиле)»
- «Напишите — разберём вашу ситуацию»

---

## Связка Instagram + Threads

Threads ≠ репост Instagram. Это отдельная точка контакта.

| Instagram | Threads |
|-----------|---------|
| Карусель с визуалом | Тред с текстовым разбором той же темы |
| Кейс с цифрами | Горячий тейк по ключевому инсайту из кейса |
| Экспертный пост | Вопрос-вовлечение по теме поста |
| Анонс / новость | Мини-комментарий + ссылка на Instagram |

Одна тема → одна карусель в Instagram + 1–2 поста/треда в Threads.

---

## Антипаттерны (не делать)

- Дублировать текст поста Instagram в Threads дословно
- Ставить хэштеги в Threads (там они не работают)
- Делать CTA «подпишись» без ценности в посте
- Писать «продолжение в шапке профиля» без реального продолжения
- Обрывать тред на полуслове — каждый пост треда = законченная мысль
