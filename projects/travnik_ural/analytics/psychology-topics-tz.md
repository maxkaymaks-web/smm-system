# ТЗ аналитику: топ-темы психологии для Травник Урала

## Контекст

Клиент (Анатолий, @travnik_ural, травник) заказал 20 постов-каруселей **про
психологию** (не про травы) — цель привлечь и удержать аудиторию между его
редкими рилсами. Темы карусели должны быть взяты из реально хорошо
выстрелившего контента у двух psychology-блогеров и переработаны под
уникальный текст/заголовок/фото.

## Задача

1. Спарсить через Apify Instagram-скрапер последние посты-карусели (за
   доступный период/лимит) у:
   - https://www.instagram.com/gulnaz.rasilevna.blog
   - https://www.instagram.com/psy.gleb
2. Для каждого аккаунта выделить **топ-15–20 постов по охватам/engagement**
   (likes+comments, или views если доступны охваты) — приоритет каруселям
   (`type: carousel`), не reels/одиночным фото.
3. Для каждого топ-поста зафиксировать:
   - тему/идею в 1 предложении (о чём пост)
   - заголовок 1-го слайда (хук)
   - почему сработало (гипотеза: боль/любопытство/список/провокация и т.п.)
   - метрики (likes, comments, дата)
4. Свести общий список **20 уникальных тем** (без дублей между двумя
   аккаунтами, с приоритетом по соц. доказательству) — это и есть пул тем для
   контент-плана клиента.
5. Сохранить отчёт в `projects/travnik_ural/analytics/psychology-topics.md`
   по стандартному формату агента analytics (см. `.claude/agents/analytics.md`,
   раздел «Задача 1: конкурентный анализ»), плюс отдельная таблица:

   | # | Тема (заголовок-хук) | Источник | Охват/ER исходника | Гипотеза почему сработало |
   |---|---|---|---|---|

## Важно

- Это НЕ контент клиента и НЕ конкуренты клиента — чисто источник тем по
  психологии с высоким откликом аудитории.
- Темы должны быть переосмыслены, не скопированы — на этом этапе нужны только
  темы/хуки, финальный текст и заголовок под бренд клиента пишет копирайтер
  отдельно.
- Ключи Apify/VK/fal — у оператора локально (в этой среде их нет). Этот файл
  — ТЗ для запуска аналитика локально; результат (отчёт) оператор вернёт в
  Claude Code для продолжения работы (контент-план → копирайтинг → дизайн).
