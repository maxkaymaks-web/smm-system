# Голос бренда: LIPS base

## Tone of Voice

Молодёжный, дружелюбный, зажигательный. Говорим с девушкой 18–22 как подруга,
которая уже умеет танцевать и зовёт попробовать.

Без снобизма, без давления. Мотивирующий, но не давящий.

## Ключевые ценности

- Движение как кайф, а не обязанность
- Танцы для всех — не надо «способностей»
- Комьюнити, теплота, принятие

## Язык

- Обращение: ты
- Короткие предложения, живая речь
- Эмодзи — умеренно, по месту
- Без официоза, без канцелярита
