# Сценарий Reels #4 — LIPS_BASE
Дата: 04.08.2026
Тип: Образовательный
Аналог: незанятая ниша — конкуренты не обучают в Reels, только показывают шоу

---

## Идея
Ещё одна пустая ниша по анализу: никто не даёт обучающий контент в Reels. Берём крутое «пугающее» движение → показываем упрощённый базовый вариант → «этому мы учим с первого урока». Снимает страх «у меня не получится» + даёт конкретную ценность (выучишь что-то прямо сейчас). Сохранения + лиды.

## Хронометраж: 30–40s

---

## ХУК — первые 2 секунды
**Тип:** Провокация-факт («выглядит сложно»)
**Текст на экране:** «Выглядит сложно? А это реально выучить за один урок»
**Визуал:** Педагог делает красивое, эффектное движение — что-то, что выглядит «как у профи».

## Инструкции по съёмке

- **Ориентация:** 9:16
- **Ракурс:** Средний / полный план. Для разбора шагов — чуть сбоку (видно тело целиком)
- **Камера:** Штатив, фиксированный угол. Для разбора — slow motion (120/240 fps)
- **Свет:** Достаточный, ровный. Видно движения тела
- **Одежда:** Комфортная для демонстрации движений. Подчёркивает пластику
- **Монтаж:** Показать элемент 3 раза: (1) быстро → пугает, (2) медленно с разбивкой, (3) снова быстро → уже красиво. Классический обучающий паттерн
- **CTA внутри видео:** Финальный кадр: «Сохрани + приходи на урок» + стрелка вниз
