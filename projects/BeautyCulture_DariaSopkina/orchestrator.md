# Проектный оркестратор: Студия красоты «Культура»

## Контекст проекта

Клиент: Студия красоты «Культура» (Дарья Сопкина, СПб)
Агентство: bit&pix · Специалист: Максим

## При каждом запуске читай (в этом порядке)

1. `projects/BeautyCulture_DariaSopkina/voice.md` — **ПЕРВЫМ, обязательно** — голос бренда
2. `projects/BeautyCulture_DariaSopkina/context.md` — контекст клиента
3. `projects/BeautyCulture_DariaSopkina/strategy.md` — стратегия
4. `projects/BeautyCulture_DariaSopkina/content-plan.md` — текущий план
5. `global/rules.md` — общие правила и правила делегирования
6. `projects/BeautyCulture_DariaSopkina/feedback/` — непрочитанный фидбек → обрабатывай первым

## Правила делегирования (см. global/rules.md)

- Текст постов → копирайтер (передавай voice.md целиком в ТЗ)
- Дизайн и HTML → дизайнер
- Анализ данных / тональности → аналитик
- Оркестратор сам: статусы, коммиты, чтение файлов

## ЖЁСТКИЕ ОГРАНИЧЕНИЯ — повторяю для агентов

- ❌ Хэштеги — полный запрет
- ❌ Скидки/акции без одобрения Дарьи
- ❌ Мифы о лазере, RSL vs LPG, лазер vs шугаринг
- ❌ Личная история Дарьи, она лично в контенте

## ТЗ для копирайтера — обязательные поля

Передавай в диспатче:
- Полное содержимое `context.md`
- Полное содержимое `voice.md`
- Релевантные правила из `global/rules.md`
- Тема, рубрика, CTA: запись через сообщения сообщества ВКонтакте
- Особые требования: без хэштегов, без скидок, экспертный тон
- Куда сохранить: `projects/BeautyCulture_DariaSopkina/posts/drafts/{дата}-{N}/post.md`

## ТЗ для дизайнера — обязательные поля

- Размер: 1080×1350px (портрет)
- Шрифт заголовков: Cormorant Garamond
- Шрифт текста: Raleway
- Светлый фон: `#F5F0EA`, тёмный: `#1a1714`
- Стиль: минимализм, плёночная эстетика
- Логотип «Культура» — top-right мелко
- Текст поста: содержимое `post.md`
- Промпт для fal.ai: из секции «Промпт для дизайнера» в `post.md`
- Куда сохранить HTML + рендер: `projects/BeautyCulture_DariaSopkina/posts/drafts/{дата}-{N}/post.html` + `.png`
