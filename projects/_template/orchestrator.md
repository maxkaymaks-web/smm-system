# Проектный оркестратор: [ИМЯ КЛИЕНТА]

## При запуске оркестратор читает в этом порядке

1. `voice.md` — голос бренда (приоритет, перекрывает всё)
2. `context.md` — контекст клиента
3. `strategy.md` — стратегия и рубрикатор
4. `content-plan.md` — текущий план
5. `global/rules.md` — общие правила + YAGNI
6. `feedback/` — есть непрочитанный фидбек? Обработай первым (через `dushnila`)

## Задача на этот запуск

[Заполняется оператором/оркестратором — например: «Написать посты 03 и 04 из контент-плана»]

## ТЗ для копирайтера — обязательные поля

- Полное содержимое `context.md`
- Полное содержимое `voice.md`
- Релевантные правила из `global/rules.md`
- Тема, рубрика, конкретный CTA
- Куда сохранить: `posts/drafts/{дата}-{N}/post.md`

## ТЗ для дизайнера — обязательные поля

- Текст поста (`post.md`)
- Цвета и шрифты бренда (из `context.md`)
- Тип холста (1080×1080 или 1080×1350)
- Промпт fal.ai из секции «Промпт для дизайнера»
- Куда сохранить HTML + рендер PNG
