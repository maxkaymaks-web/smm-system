## Текст поста

Учёный в поле — это не маркетинговый кадр. Это базовый этап работы над любым проектом восстановления водоёма.

Каждый проект начинается с экспедиции на объект. Команда выезжает в любую точку РФ — от ХМАО до Краснодара — и проводит на месте 2–5 дней.

**Что мы измеряем в поле 🔬**

→ Растворённый O₂ — глубинный профиль, не поверхностный замер

→ Окислительно-восстановительный потенциал (Eh) — для оценки анаэробных зон

→ Состав донных отложений — кернение и лабораторный анализ

→ Эвтрофикационную нагрузку — азот, фосфор, источники поступления

Без этих данных расчёт оборудования становится слепым. На разные водоёмы — разная компоновка аэратора МГ, разная глубина установки, разная производительность.

**ESG-контекст для крупных предприятий 🌿**

Восстановление одного загрязнённого водоёма закрывает строки ESG-отчётности по трём направлениям нацпроекта «Экология»:

→ Сохранение биоразнообразия

→ Снижение метана (CH₄) от анаэробного разложения донных отложений — × 50 в CO₂-эквиваленте

→ Возврат водного объекта в водохозяйственный оборот

Для компаний с обязательствами по устойчивому развитию это конкретные позиции в годовом отчёте, а не «вклад в зелёную экономику».

## Заметки по визуалу

Прошлый пост (#04 «0,8 руб/м³») — типографическая инфографика на тёмном фоне (#1B1A24), зелёный акцент на цифре, без живых фото. Сухой data-style.

Для этого поста — отстройка: живая «полевая» эстетика. Учёный/команда + водоём + приборы. Четыре варианта стиля для выбора:

1. **Документальный репортаж** — натуральный свет, прямой кадр, без постановки. Эстетика National Geographic.
2. **Cinematic / atmospheric** — пасмурное небо, глубина резкости, крупный план рук с пробой воды. Эстетика Apple/Tesla про инженерию.
3. **Editorial-научный журнал** — двойная композиция, прибор + образец, лабораторная чёткость в полевых условиях. Эстетика Nature / Wired.
4. **Tech-style high angle / дрон** — масштабный кадр водоёма с командой и оборудованием сверху. Эстетика drone-startup.

Все варианты в портретной ориентации 3:4 (под ВК-карусель). Без постановочных стоковых лиц.
