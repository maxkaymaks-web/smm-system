# Проектные оверрайды: bit.and.pix

Проектные дополнения и исключения поверх `context.md` / `voice.md` / `strategy.md`
и `global/rules.md`. Что не задано здесь — берётся из общих правил.

## Жёсткие ограничения проекта

- **Без цен и тарифов** — ни на Агента, ни на услуги студии (ни намёка, ни «от X руб.»)
- **Без хэштегов** — Instagram-аккаунт новый, хэштеги не используем до отдельной команды
- **Instagram:** только карусели в ленту — Reels и сторис не делаем на старте
- **Threads:** одиночные посты и треды. Без хэштегов. Без дословного дублирования с Instagram
- **Без живых съёмок** — только существующие материалы + AI-генерация
- **Без упоминания конкурентов по имени**
- **Чередование тем/фонов**: тёмный пост → светлый пост → тёмный. Не нарушать.

## Дизайн-спеки

### Холст
- Размер: **1080 × 1350 px** (вертикаль, Instagram карусель)

### Цвета
| Название | HEX | Применение |
|----------|-----|------------|
| Red | `#FF1E1E` | Акценты, теги-навигация, блоки-выделения |
| Orange | `#FF4A18` | Дополнительный акцент (используется редко) |
| Black | `#0B0B0B` | Фон тёмных постов, текст на светлых |
| Snow | `#F6FAFC` | Фон светлых постов |
| White | `#FFFFFF` | Фон светлых вариантов, текст на тёмных |

### Типографика
- **CA Saygon** — заголовки, ключевые тезисы
- **Nata Sans** — тело, подписи, мелкий текст (Light, Regular, Medium, Bold, ExtraBold — все веса)

### Логотип
- **Версия EN: `bit&pix.`** (всегда английская версия)
- На тёмном фоне (#0B0B0B): **белый логотип**
- На светлом фоне (#F6FAFC / #FFFFFF): **чёрный логотип**
- На красном фоне (#FF1E1E): **белый логотип**

### Паттерн
- Скруглённые квадраты-пиксели — декоративный элемент
- Используется как фоновый орнамент или акцентная деталь

### Принципы дизайна
- Контраст + модульность + иерархия
- Красные блоки — для ключевых сообщений / выводов
- Красные теги (#FF1E1E) — навигация между слайдами
- Сетка: чёткая, нет хаотичного расположения элементов
- Отступы: щедрые, воздух важен

### Тёмный пост (нечётные в ленте)
- Фон: `#0B0B0B`
- Текст: `#FFFFFF`
- Акцент: `#FF1E1E`
- Логотип: белый

### Светлый пост (чётные в ленте)
- Фон: `#F6FAFC` или `#FFFFFF`
- Текст: `#0B0B0B`
- Акцент: `#FF1E1E`
- Логотип: чёрный

## ТЗ копирайтеру — обязательные поля

Всегда указывать в ТЗ:
- Тема карусели + рубрика (Агент / Экспертиза / Кейс / Закулисье)
- Тема фона: тёмный или светлый (из чередования)
- Количество слайдов (рекомендуем 5–8)
- CTA последнего слайда (например: «Запишитесь на демо», «Напишите нам»)
- Конкретные цифры/факты для слайдов (не выдумывать)

## Визуальный стиль карточек/слайдов (референс 29.06.2026)

- Жирный гротеск (типа Helvetica/Inter Bold), крупные заголовки капсом,
  плотный трекинг.
- Контрастные фоновые варианты: чёрный фон + красный акцентный текст/слово;
  красный градиентный фон + белый текст; белый фон + красный заголовок и
  чёрно-белое фото.
- Акцентное слово в заголовке — красным (#FF2A1A-ish), остальной текст — белый
  или чёрный.
- Подпункты/пилюли (rounded pill-бейджи) для списков типа «Reels / TikTok /
  Likee».
- Эмодзи-маркеры перед короткими тезисами (например 🔥 100% гарантия просмотров).
- Лого bit&pix внизу слайда (ч/б вариант «bit&pix.» с красным амперсандом в
  речевом облаке) — всегда присутствует, обычно в углу.
- Карусели: последний/один из слайдов может содержать горизонтальную полосу
  мини-кадров (превью видео) под основным текстом.
- Тон текста на слайдах — короткий, про конкретную выгоду/фичу сервиса
  (вирусные сценарии, гарантия возврата, ИИ-фабрика).

## Накопленные правила (из ОС и правок)

> Новые — сверху.

- [2026-06-30] **Лого — только оригинал**, никогда не текст/самодельный SVG.
  Оператор дважды поправил после того, как логотип воссоздавался вручную
  (инлайн HTML-текст «bit&pix.», потом самодельный SVG) — выглядело как
  подделка. Оригиналы: `global/brand/logo_black.png` (чёрный, на светлом фоне)
  и `logo_white.png` (белый, на тёмном/красном фоне) — вставлять `<img>` с
  этими файлами, никогда не реконструировать текстом или SVG. Логотип —
  единственный элемент, который заказчик узнаёт мгновенно; малейшее
  расхождение с оригиналом читается как «не тот» бренд.
- [2026-06-29] **Без хэштегов** — Instagram-аккаунт новый, хэштеги не
  используем ни в Instagram, ни в Threads до отдельной команды.
- [2026-06-29] **Эмодзи 1–3 на пост**, по смыслу (крючок / ключевой акцент /
  CTA), не декор, без точки перед ними. Перед отправкой любого caption для
  bitnpix проверять: (1) нет `#` в конце, (2) эмодзи ≤3, (3) нет цен/тарифов,
  (4) нет «индивидуального подхода»/канцелярита. Оба правила уже были в
  `voice.md`/`overrides.md`, но не были применены к тексту (только к дизайну) —
  сверяться перед выдачей текста, не только перед вёрсткой.
