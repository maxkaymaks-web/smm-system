## Выводы для bitnpix

### Что работает у всех трёх
1. **Карусели** — основной формат (80–100% постов). Алгоритм Instagram и аудитория digital-ниши их любят
2. **Comment-bait** — единственный механик, дающий кратный ER. У @dayanamaksim топ-3 поста с триггером = ER 33–40%, без — 1–9%
3. **Практический контент**: подборки инструментов, методики, чек-листы — лучший органический охват

### Что не делает никто (пустые ниши)
- Никто не показывает **процесс работы digital-студии изнутри** (за кулисами: разработка SMM-стратегии, работа с клиентом, правки)
- Нет **кейсов с цифрами** «было/стало» для конкретных клиентов — только абстрактные советы
- Нет **контента про ошибки** агентства и уроки из них (честный провальный кейс = высокое доверие)

### Рекомендации для bitnpix
1. **Comment-bait как основа** — каждый пост про инструменты/методики закрывать триггером: «Пиши X — пришлю шаблон/чек-лист/файл». Это единственное, что даёт ER >5% в нише
2. **Карусели 70% / видео 30%** — стартовать с каруселями, постепенно добавлять видео (wavvve.academy показывает, что видео дают сопоставимый ER)
3. **Частота 3–4 поста/неделю** — золото у @dayanamaksim. Не перегружать как @wavvve.academy (выгорание), не пропадать как @mads_courses
4. **Темы с потенциалом**: AI-инструменты в SMM (тренд @dayanamaksim), кейсы клиентов bit&pix с цифрами, «как мы делаем» — этого нет ни у кого из трёх
5. **Хуки**: «5 сайтов вместо X», «как мы за N дней», «ошибка которую делают 90%» — ресурсные подборки дают стабильный охват даже без comment-bait (лучший пост @mads_courses)
