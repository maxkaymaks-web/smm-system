# Настройки агентов: Sparta

> Заполняется специалистом после брифа.

## О проекте

ООО «Спарта» / Sparta Technology — стратегический консалтинг для университетов,
регионов и корпоратов (B2B/B2G). Сайт sparta-tech.ru, Telegram @sparta_technology
(с нуля).

Платформа: **Telegram**, 3 поста/нед (Пн/Ср/Пт). Рубрики: E1 авторский разбор,
E2 ИИ в управлении, E3 принцип работы, N1 дашборд лидера, M1 пострелиз
мероприятий. Бренд: Gilroy + Gotham, оранжевый + белый/серый/чёрный. ToV —
профессиональный, без пафоса, умеренный объём.

Серия про тренинги предпринимательских компетенций в СФУ (Пузин, апрель 2026) —
материалы клиент присылает галереями PhotoPrism (sfu-kras.ru), отдельные ссылки
на дни съёмки; идёт в рубрику M1. При отборе кадров — единая стилистика (свет,
локация, тон), разные лица, читабельный текст с «хуком» в начале. Жёсткие
запреты: критика системы/министерств, «успешный успех» без цифр, конфиденциальные
кейсы, упоминание конкурентов по имени.

Дефолт для одиночного изображения в постах Sparta — **4:5 (1080×1350)**.

## Накопленные правила (из ОС и правок)

> Новые — сверху.

- [2026-05-28] Авторский голос в постах Sparta — **«мы»**, не «я» (клиент,
  дословно: «Только не я, а мы. Запомни это»). Перекрывает прежнюю запись в
  `strategy.md` («Автор говорит «я», не «мы»» — устарело). Примеры замен:
  «я провёл»→«мы провели», «у меня»→«у нас», «благодарю»→«благодарим»,
  «отыграл»→«отыграли». Не использовать «авторский голос»/«от первого лица»
  как ориентир. Не меняется: деловой регистр без пафоса, запреты (критика
  министерств/конфиденциальные кейсы/«успешный успех»), структура постов
  (крючок → благодарность → наблюдение → CTA), эмодзи-маркеры 1–2–3 на пост.
  **Тех. долг:** `strategy.md` (раздел Tone of Voice) и, возможно, `context.md`
  всё ещё могут содержать «я»-формулировки — поправить при следующей правке.
- [2026-05-21] Форматирование текстовых постов в Telegram: заголовок пункта
  (эмодзи-цифра + текст) и тело пункта — без пустой строки между ними, всё
  подряд; между пунктами тоже без пустой строки (плотный блок); заголовок
  пункта — **без жирного**, обычный текст; пустая строка только между
  логическими блоками (вводный абзац / блок пунктов / заключение); ссылка в
  конце — сразу после призыва, без пустой строки. Дано при правке поста #08
  (акселератор) — убран жирный с заголовков и лишние отступы.
