# Сценарий Reels #3 — NOVYE_LYUDI
Дата: 27.07.2026
Тип: Relatable / Юмористический скетч
Формат: «Читаем законопроект»

---

## Идея

Два анимированных / нейро AI-персонажа читают реальный официальный текст закона
и реагируют — юмор через абсурд самих формулировок.
Без выдумки: только реальные цитаты + живые реакции.
Финал тихий: «Кто-то проголосовал против. Найди имя.»

Вирусная механика: «POV: читаешь законопроект», репосты, «это уже происходит», узнаваемость абсурда.

## ХУК — первые 2 секунды

**Тип:** Узнай себя / абсурд
**Текст на экране:** `Так, что там в новом законопроекте...`
**Визуал:** AI-персонаж #1 открывает документ с заголовком «Законопроект №XXXX» (читаемо). Гримаса замешательства.

## Инструкции по генерации

- **Персонажи:** 2 абстрактных AI-персонажа (не реальные лица). Стиль: Pixar-like или семиреалистичная анимация. Возраст 20–27, нейтральный облик.
- **Инструмент:** fal.ai video + Adobe Express анимация / HeyGen AI / D-ID для lip-sync нейро-голоса
- **Голос:** нейро-TTS (11labs или аналог), два разных голоса — один чуть выше (удивление), другой ниже (сухой юмор)
- **ВАЖНО:** реальный текст закона использовать из официального источника (sozd.duma.gov.ru). Не придумывать цитаты. Редактор подбирает конкретный законопроект перед монтажом.
- **CTA внутри видео:** в финале — «Сохрани» мелким текстом
