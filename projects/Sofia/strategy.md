# Контент-стратегия: ЭНЖЕ Стоматология

## Цели

- 30–45 лидов/неделю с 2-го месяца
- Рост ER с 0.07% до 1%+
- Рост подписчиков органически через Reels
- Укрепление доверия через экспертность и истории пациентов

## Позиционирование в контенте

**Не продаём процедуры — продаём трансформацию и доверие.**

- Главный герой контента = пациент, не врач
- Врач = доверенный эксперт, не рекламный образ
- Продаём: спокойствие, безопасность, красивую улыбку, уверенность
- Не продаём: инструменты, технологии ради технологий, акции

## Reels-формула (по референсу YourClinic.ru)

```
ДО (крупный план → проблема) 
→ История пациента (страхи, почему тянул)
→ Экспертное решение врача (что и как)
→ Процесс (коротко, без страшного)
→ Результат (эмоция + улыбка)
→ Цена (если возможно — назвать)
→ CTA (запись в директ / Телеграм)
```

## Конкурентная стратегия

**YourClinic.ru** — референс по Reels-формуле и сторителлингу. Берём: пациент-герой, сильный контраст до/после, прозрачность цен.

**InWhite.Medical** — референс по премиальному позиционированию. Берём: атмосфера клиники, экспертные видео врачей, семейный формат.

**Наше отличие от обоих:** локальная казанская клиника + семейный формат + лечение во сне + честный сервис без давления. Конкурируем репутацией, а не ценой.

## Площадки

- **Instagram** — основная. Reels для привлечения, сторис для прогрева и записи

## KPI

- Охват Reels: 5000+ на старте → 15 000+ к 3-му месяцу
- ER: 0.5%+ к концу 2-го месяца
- Лиды: 10+ в неделю с 1-го месяца, 30–45 со 2-го
- Прирост: 500+ подписчиков/месяц через Reels

## Форматы (приоритет)

1. **Reels talking head** — врач говорит в кадре (главный)
2. **Reels войсовер** — голос за кадром + процесс/результат
3. **Карусели** — экспертный контент, мифы, инструкции
4. **Сторис** — ежедневно, прогрев + запись
