# Сценарий Reels #13 — LIPS
Дата: 27.07.2026
Тип: Брендинг / Relatable
Аналог: Тренд «meet the team» — знакомство с командой

---

## Идея

«Познакомьтесь с LIPS». Быстрое интро каждого артиста: имя → специализация (акробатика / хореография / вокал / и т.д.) → одно фирменное движение. Финал — вся команда в кадре. Строит доверие: у бренда есть лица, характеры, люди. Один из самых мощных форматов для аккаунтов с командой.

## Хронометраж: 25–30 сек

---

## ХУК — первые 2 секунды

**Тип:** Прямое знакомство + интрига
**Текст на экране:** «Мы — LIPS. И у каждого из нас — свой суперталент.»
**Визуал:** Вся команда выстроена в ряд, смотрит в камеру. Момент перед тем, как начнут представляться.
**Почему цепляет:** Групповой кадр = масштаб + профессионализм. «Суперталент» — интрига: хочется узнать, у кого какой.

## Инструкции по съёмке

- **Индивидуальные блоки:** Каждый артист — одно движение, которое раскрывает его специализацию. Максимум 3–4 секунды.
- **Фон:** Одинаковый для всех — единство стиля. Чёрный фон или студийный нейтральный.
- **Одежда:** Фирменный стиль LIPS — одинаковая или скоординированная для всех.
- **Финал:** Все вместе — обязательно. Синхронное движение даже простое (поворот, жест, поза).
- **Темп:** Быстро. Зритель должен чувствовать энергию команды, не скучать на каждом артисте.

## Музыка

**Трек:** Уверенный поп или R&B с чётким ритмом. Движения каждого артиста совпадают с ударами.
**Ориентир:** Beyoncé — «Run The World» / любой confident girl/group anthem
**Почему:** «Meet the team» требует музыки с характером и гордостью — не агрессией, а уверенностью.
