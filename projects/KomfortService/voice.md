# Голос бренда — Комфорт Сервис

## Тон

Уверенный практик. Не продаёт — показывает решение. Говорит коротко и по делу.
Без пафоса, без лишних эмоций. «Профессионал у которого есть ответ на твою проблему».

## Язык

- Простые короткие предложения
- Конкретика: материал, замок, размер, срок
- Без «мы рады предложить», без канцелярита
- Можно на «ты» (ЦА 30-35+, нет формальных барьеров)

## Запрещено

- Восклицательные знаки через слово
- «Скидки только сегодня»
- Абстрактные обещания без конкретики
