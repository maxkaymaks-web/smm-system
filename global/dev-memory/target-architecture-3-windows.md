Видение начальника «одно окно» приземлено разработчиком (Pavel) в **3 окна + Notion-БД за ними**, на готовых инструментах (не кастомное приложение):

- **Окно 1 — Chatwoot** — клиентские диалоги, омниканал TG/VK/MAX. Развёрнут (шлюз — `smm-app/temp/chatwoot-gateway/`).
- **Окно 2 — Claude Code** — ОСНОВНОЙ рабочий экран оператора: подсказывает что следующим, вместе делают пост, ведёт Notion. Готовый пост оператор **публикует руками** в соцсети.
- **Публикация — вручную.** Postiz пробовали как окно превью/автопостинга, но **не интегрировали — отказались**; оператор постит сам. Автопостинг — кандидат в кабинет (smm-app, позже).
- **Notion** — БД/источник истины операционки + Kanban для начальника. Ведёт Claude; начальник смотрит/иногда правит; рядовой оператор руками почти не лезет.
- **Медиа — S3 Timeweb** (бакет `seo`, префикс `smm/`). Google Drive рассматривали и **отказались 14.06.2026** (SA не пишет в личный My Drive после 15.04.2025; Workspace не оплатить из РФ; личный OAuth хрупко). Директору — Cyberduck; клиентам — presigned. Знания (voice/context/strategy/overrides) — локально в git (Вариант А). Логи сессий — S3 (`logs/claude-code/…`).
