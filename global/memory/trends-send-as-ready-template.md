Разбор тренда (приём, примеры, описание) можно проговорить кратко, но сам пост —
даже на черновом этапе, до подтверждения ID и типа — присылать сразу собранным
по шаблону из `docs/trends.md`: эмодзи+название, ✨Примеры, ✨Описание, ID,
ссылки, хештег. Целиком как в примере, который прислала Настя, plain text
(см. `trends-post-plain-text.md`), без разбивки на «Название:», «Описание:»,
нумерованных списков с жирным.

Если ID/тип ещё не известны — оставить плейсхолдер (`ID: BPTxxx`, хештег по
уточнении типа), но структуру и текст самого поста собирать сразу целиком.
