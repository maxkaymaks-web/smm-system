Всегда отправлять готовый PNG/файл на рабочий стол после каждого изменения —
без вопроса «отправить?».

**Why:** оператор явно попросил «всегда отправляй изменения» (05.06.2026).

**How to apply:** после рендера PNG сразу копировать на Desktop и сообщать
«готово, на рабочем столе». Исключение — проекты, где хранилище медиа
принципиально другое (например Lakmoda ведёт готовые медиа в S3, см.
`projects/Lakmoda/overrides.md` → «Хранилище медиа»); там уточнить у оператора
формат передачи, если не задан явно.
