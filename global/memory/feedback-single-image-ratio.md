Если пост содержит одно изображение, оно должно быть в одном из стандартных
соотношений:
- **16:9** (1080×608) — горизонтальное
- **1:1** (1080×1080) — квадрат
- **4:5** (1080×1350) — вертикальный портрет (предпочтительно для feed)
- **5:4** (1080×864) — широкий портрет

**Why:** Telegram и Instagram обрезают или добавляют поля к нестандартным
соотношениям. 9:16 — только для stories и reels, не для feed.

**How to apply:** при рендере HTML-постера для одиночного фото задавать
width=1080 и height под нужное соотношение (аргумент 1080 для
`tools/render-html.js`). Дефолт по проекту может отличаться — см.
`projects/{ProjectID}/overrides.md` (например у Sparta дефолт 4:5).
