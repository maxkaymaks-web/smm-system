Тип для кабинета и хештег поста определяет слово, которым Настя называет задачу:

- «делаем тренд» → `trend`, `#тренд`
- «делаем микротренд» → `microtrend`, `#микротренд`
- «делаем мем» → `meme`, `#мем`

Слово «тренд» в запросе означает именно тип `trend`, а не любой ролик для
канала. Даже если по сюжету ролик похож на мем (склейка с кадром из фильма),
тип не менять. Если слова-типа в сообщении нет, спросить перед загрузкой.

Правка Насти, 2026-10-07, BPT105: «это тренд, я ж написала». Я загрузила его как
мем, исправляли через PATCH.

Обратный случай, 2026-10-17, BPT121 («Мы в детстве», обезьяна и мужчина
держат друг друга за волосы): Настя написала «делаем новый тренд», а по факту
это был мем, тип правили через PATCH на `meme`. Слово «тренд» Настя иногда
пишет про любой ролик для канала. Если в запросе «тренд», а видео похоже на мем
(фото или кадр с вопросом, склейка с чужим смешным роликом, подпись-панчлайн),
перед загрузкой коротко уточнить тип.
