# Память оператора (git, общая для всех операторов)

> Замена выключенной личной памяти Claude (`autoMemoryEnabled: false` в
> `.claude/settings.json`). Читается явным шагом в начале каждой сессии (см. `CLAUDE.md`).

## Что сюда писать

Долгоиграющие **операторские** факты, которые помогают в работе с клиентами и
которых ещё нет в `CLAUDE.md` / `global/rules.md` / `docs/`: повторяющиеся грабли
платформ, «так у нас принято», устойчивые особенности процесса.

**НЕ сюда:**
- **Правки/предпочтения конкретного клиента** → `projects/{ProjectID}/overrides.md`
  (секция «Накопленные правила») или `feedback/`. См. «Фиксация правок клиента» в
  `global/rules.md`.
- **Инфраструктура, серверы, SSH, интеграции, внутренняя кухня** → это
  **разработческое**, в `global/dev-memory/` (оператор туда не пишет и на серверы
  не лезет — см. правило о ролях в `CLAUDE.md`).
- Разовые события сессии, промежуточные результаты, то что есть в коде/доках.

## Формат

Один факт = один файл `<slug>.md` рядом + строка-указатель в этот индекс.
Frontmatter: `name`, `description` (по ней решаем релевантность), `metadata.type`.
