Ссылки нужны, но URL не должен торчать наружу. Правильный формат — текст-ссылка без видимого URL (Telegram markdown):

[сервис для создания сценариев](https://app.bitandpix.ru) | [услуги: smm, дизайн, продакшн](https://bitandpix.ru)

Текст анкоров фиксирован: «сервис для создания сценариев» и «услуги: smm, дизайн, продакшн».

Неправильно (голый URL):
сервис для создания сценариев: https://app.bitandpix.ru | услуги: smm, дизайн, продакшн: https://bitandpix.ru
