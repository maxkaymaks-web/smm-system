После изменения файлов в репо коммит и пуш делаем сразу, не спрашивая. Правка
Насти, 2026-10-10, BPT107: «коммить и пушь без моего согласия в след раз».

Это перекрывает правило из `AGENTS.md` «спрашивать подтверждение перед
`git commit` и `git push`» для сессий Насти. Остальное как было:

- в коммит берём только файлы, которые меняли в этой сессии, чужие правки в
  рабочем дереве не трогаем;
- коммит без пуша не оставляем;
- если `push` не проходит (кто-то запушил раньше), подтягиваем `git pull --rebase`
  и пушим снова; конфликт - сообщить, молча не форсить.
